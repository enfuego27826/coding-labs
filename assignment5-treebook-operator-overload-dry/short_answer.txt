Q1 (DRY — Part 3).
    Quote the exact lines or expressions that were duplicated between your
    Part 2 copy constructor and copy assignment. Which of the two refactors
    did you choose (helper method, or copy-and-swap), and how does it
    eliminate that duplication? If you chose copy-and-swap, also explain
    why it is exception-safe.

    YOUR ANSWER:
    the duplicated code between my copy ctor and copy assignment op was allocation and
    copying of the friend array

    _friends = new std::string[_capacity];

    for (size_t i = 0; i < _size; ++i) {
        _friends[i] = user._friends[i];
    }

    i chose the copy and swap idiom. the copy ctor contains the copying logic and copy assignment op
    takes the argument by value and swaps its content with the current object 

    User& User::operator=(User user) {
        swap(*this, user);
        return *this;
    }

    this removes the duplication of code. it is excpetion safe because the copy of user is 
    created before any changes are made and if copying fails the current obj remains the same. 
    also about memleaks, the temp object's destructor will be called at the end of function. it
    probably adds more overhead but it looks really neat.
